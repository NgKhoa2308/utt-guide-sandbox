# UTT Student Guide

Cẩm nang số cho sinh viên UTT — giúp tìm nhanh các địa điểm và dịch vụ cần thiết xung quanh trường.

## 🎯 Mục tiêu

Tập trung thông tin địa điểm (ăn uống, photocopy, sửa xe, nhà thuốc, học nhóm...) vào một hệ thống duy nhất, tổ chức theo nhu cầu thực tế của sinh viên UTT.

## 🧭 Luồng chính

Tìm → Lọc → Xem → Định vị → Chỉ đường
